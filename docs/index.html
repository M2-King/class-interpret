开始使用

  1. 下载 0.3.3 zip。左上角必须显示 0.3.3。
  2. Mac 解压后双击 Open.command，不要只点应用图标。
  3. Windows 必须右键 zip → Extract All，再双击 OPEN-THIS.bat（或文件夹里的 Start.bat）。不要在压缩包窗口里打开。不要覆盖已经能用的 R9000P 文件夹。
  4. 校园网失败时换手机热点，用黄色按钮下载语音/翻译模型（建议 Small）。
  5. 下课后点「生成课后总结」。DeepSeek 已打进这个版本，朋友不用再填 key。

已经能用的电脑请继续用原来的文件夹。新 zip 是安装包，不会更快。
