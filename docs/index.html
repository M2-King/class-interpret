按设备安装

Windows 笔记本

安装器：ClassInterpreter-Setup-Windows.bat

  1. 双击安装器。它会自动下载完整 zip、解压并寻找旧安装路径。
  2. 安装或修复完成后会自动启动。黑窗口不要关。
  3. 浏览器打开 http://127.0.0.1:8765/，左上角必须是 0.3.3，点黄色按钮，模型选 Small。
  4. 若提示 SmartScreen：更多信息 → 仍要运行。
  5. 以后损坏时，双击主文件夹里的 FIX-CLASS-INTERPRETER.bat。

下载完整 Windows 便携包（手动 Extract All → OPEN-THIS.bat）。

解压后路径：ClassInterpreter-0.3.3\Start.bat · 环境 .venv\ · 模型 hf\ · 笔记 data\

Mac

安装器：ClassInterpreter-Setup-Mac.zip

  1. 解压这个很小的安装器 zip，双击 ClassInterpreter-Setup-Mac.command。
  2. 它会自动下载完整应用、寻找旧版并安装到合适位置。
  3. 若无法打开：Control 点 Open.command → 打开；或系统设置 → 隐私与安全性 → 仍要打开。
  4. 左上角应为 Class Interpreter · 0.3.3。黄色条下载模型，建议 Small / Medium。
  5. 以后损坏时，双击应用旁的 FIX-CLASS-INTERPRETER.command。

下载完整 Mac 便携包（手动解压 → Open.command）。

运行文件：~/Library/Application Support/ClassInterpret · 日志 ~/Library/Logs/class-interpret.log

iPhone / iPad

手机不能单独装同传。必须先有一台已打开的电脑。

  1. 先在 Mac 上打开听课搭子。
  2. 再双击 听课搭子手机.app（或 手机访问.command）。
  3. 把弹出的 https://….trycloudflare.com 发到手机。
  4. 用 Safari / Chrome 打开（不要用微信内置浏览器），允许麦克风。
  5. 上课时保持页面在前台。下课后在 Mac 终端 Ctrl+C 关掉隧道。

手机打不开电脑上的 http://127.0.0.1:8765/，必须用 https 链接。

开始使用

  1. 下载上面的独立安装器。它会自动下载完整 0.3.3 包并检测旧路径。
  2. Mac：解压小安装器后双击 ClassInterpreter-Setup-Mac.command。
  3. Windows：直接双击 ClassInterpreter-Setup-Windows.bat。
  4. 校园网失败时换手机热点，用黄色按钮下载语音/翻译模型（建议 Small）。
  5. 下课后点「生成课后总结」。DeepSeek 已打进这个 zip，朋友不用再填 key。

安装器会优先修复已有路径，并保留录音、模型和设置。

主文件夹里的 FIX 命令会重新下载干净文件并自动备份被替换的应用文件。
