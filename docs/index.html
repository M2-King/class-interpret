按设备安装

Windows 笔记本

安装包：ClassInterpreter-windows.zip（当前 0.3.3）

  1. 右键 zip → Extract All。不要在压缩包窗口里双击。
  2. 双击 OPEN-THIS.bat。黑窗口不要关。第一行必须是 Class Interpreter 0.3.3。
  3. 浏览器打开 http://127.0.0.1:8765/，左上角必须是 0.3.3，点黄色按钮，模型选 Small。
  4. 若提示 SmartScreen：更多信息 → 仍要运行。
  5. 已经删掉 .venv：换手机热点，解压到新文件夹再 OPEN-THIS.bat。第一次会重新装包几分钟。

解压后路径：ClassInterpreter-0.3.3\Start.bat · 环境 .venv\ · 模型 hf\ · 笔记 data\

Mac

安装包：ClassInterpreter-mac.zip（当前 0.3.3）

  1. 双击 zip 解压，进入 ClassInterpreter-mac-0.3.3。
  2. 双击 Open.command。不要只点「听课搭子」图标。
  3. 若无法打开：Control 点 Open.command → 打开；或系统设置 → 隐私与安全性 → 仍要打开。
  4. 左上角应为 Class Interpreter · 0.3.3。黄色条下载模型，建议 Small / Medium。
  5. 苹果芯片用 CPU。可把 听课搭子.app 拖到「应用程序」。

运行文件：~/Library/Application Support/ClassInterpret · 日志 ~/Library/Logs/class-interpret.log

iPhone / iPad

手机不能单独装同传。必须先有一台已打开的电脑。

  1. 先在 Mac 上打开听课搭子。
  2. 再双击 听课搭子手机.app（或 手机访问.command）。
  3. 把弹出的 https://….trycloudflare.com 发到手机。
  4. 用 Safari / Chrome 打开（不要用微信内置浏览器），允许麦克风。
  5. 上课时保持页面在前台。下课后在 Mac 终端 Ctrl+C 关掉隧道。

手机打不开电脑上的 http://127.0.0.1:8765/，必须用 https 链接。

开始使用

  1. 只下载上面的 zip（文件名固定为 ClassInterpreter-mac.zip / ClassInterpreter-windows.zip）。等 Chrome 下完。页面左上角必须显示 0.3.3。
  2. Mac：解压后双击 Open.command。
  3. Windows：Extract All，再双击 OPEN-THIS.bat 或文件夹里的 Start.bat。不要覆盖已经能用且仍有 .venv 的旧文件夹。
  4. 校园网失败时换手机热点，用黄色按钮下载语音/翻译模型（建议 Small）。
  5. 下课后点「生成课后总结」。DeepSeek 已打进这个 zip，朋友不用再填 key。

已经能用的电脑请继续用原来的文件夹。新 zip 是安装包，不会更快。

黑窗口出现 cutionPolicy：那是旧启动器，请改用当前 Windows 0.3.3 包里的 Start.bat。
