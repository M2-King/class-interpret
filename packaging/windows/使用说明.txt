听课搭子 Windows 0.3.3

Windows 用法（二选一）

A. 这台电脑以前已经能用（例如 R9000P 旧文件夹）
   不要用 Downloads 里的新 zip 覆盖。
   打开原来那个带 .venv 的文件夹，双击 Start.bat。
   黑窗口不要关。浏览器应打开 http://127.0.0.1:8765/

B. 这台电脑第一次用
   1. 下载 ClassInterpreter-windows-0.3.3.zip，等 Chrome 下完，不要打开 .crdownload。
   2. 右键 zip → Extract All。不要在压缩包窗口里双击。
   3. 双击 OPEN-THIS.bat。第一行必须是 Class Interpreter 0.3.3。
   4. 这个包已带 Python。黑窗口不要关。校园网失败请换手机热点。
   5. 浏览器左上角必须是 0.3.3。点黄色按钮，模型选 Small。

不是电脑坏了，也不是显卡问题。不要在压缩包窗口里直接打开。

如果黑窗口写着 0.2.5、0.3.1 或 0.3.2，说明打开的是旧文件夹。

如果已经删掉 .venv：换手机热点，右键新 zip → Extract All，双击 OPEN-THIS.bat。
第一次会重新装依赖，黑窗口不要关。然后点黄色按钮下载 Small 模型。
