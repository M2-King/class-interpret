Class Interpreter 0.3.3 for Windows
===================================

How to use Windows (pick A or B)

A. This laptop already ran Class Interpreter (R9000P / old folder)
   Do NOT use the new Downloads zip.
   Open the old folder that contains .venv
   Double-click Start.bat
   Keep the black window open. Browser: http://127.0.0.1:8765/

B. First copy on this laptop
   1. Download ClassInterpreter-windows-0.3.3.zip and wait until Chrome finishes.
      Not a .crdownload file. Not ClassInterpreter-windows (1).
   2. Right-click the zip -> Extract All. Do not double-click inside the zip.
   3. Open the new folder. Double-click OPEN-THIS.bat
      First line must say Class Interpreter 0.3.3
   4. Keep the black window open. First run installs packages (phone hotspot
      if campus Wi-Fi fails). This zip already contains Python 3.12.
   5. Browser top-left must say 0.3.3. Click the yellow buttons. Choose Small.

If Windows says Windows protected your PC: More info -> Run anyway.

If the black window says 0.2.5-0.3.2, you opened an old folder.

If the black window says cutionPolicy, you clicked the old UTF-8 starter.
Close every black window. Double-click Start.bat. First line must be 0.3.3.
If the page still shows v0.2.2, the old server is still running; click Start.bat again.

If you deleted .venv: that is OK. Use a phone hotspot, then OPEN-THIS.bat.
First run recreates packages (several minutes). Keep the black window open.
