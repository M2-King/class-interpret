Class Interpreter 0.2.7 for Windows
===================================

The zip name must be ClassInterpreter-windows-0.2.7.zip
Wait until Chrome finishes. Do not open a .crdownload file.
Do not open a folder named ClassInterpreter-windows (1).

1. Delete any old unzipped folder from a previous download.

2. Unzip, then open the ClassInterpreter-0.2.7 folder.

3. Double-click Start.bat
   The first line must say Class Interpreter 0.2.7
   Do NOT double-click start.ps1

4. First run downloads official Python 3.12 into this folder.
   You do not need to install Python yourself.
   Keep the black window open. Use a phone hotspot if campus Wi-Fi fails.

5. Wait for the browser. Top-left must say 0.2.7

6. Click the yellow buttons to install the Chinese translation model
   and the speech model. Choose Small if the network is slow.

If Windows says Windows protected your PC: More info -> Run anyway.

If the black window says 0.2.5, Unexpected token, or Python not found
WITHOUT Downloading official Python: you opened an old folder.
